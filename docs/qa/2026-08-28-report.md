## Defects found and fixed in this run

1. **First-visitor zeroed console (critical)** — `Number(localStorage.getItem(x))`
   maps a missing key's `null` to `0`, initializing temp/top-p to zero for
   every new visitor: a nearly empty hero. Fixed in `StageScript.astro`
   (`raw === null ? NaN : Number(raw)`); verified on a fresh origin.
   Regression note added to the runbook.
2. **Stale preview server** — an orphaned process on port 4321 served a
   previous build, producing phantom 404s. Killed; runbook note added.
