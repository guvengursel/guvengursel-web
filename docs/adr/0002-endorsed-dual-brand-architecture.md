# ADR 0002: Use an endorsed dual-brand portfolio architecture

- Status: Superseded in brand-role allocation by ADR 0004; retained as historical portfolio evidence
- Date: 2026-07-31
- Decision owner: Güven Gürsel (Kaptan)
- Supersedes: the assumption that one public site must carry every professional and creator audience
- Does not supersede: release authority, privacy, accessibility, or exact-artifact gates

> Supersession notice (2026-08-01): ADR 0004 keeps the endorsed portfolio relationship but moves enterprise AI consultancy into River Runs Again alongside the creator lab. guvengursel.com remains the founder and personal trust surface. The allocation below is historical, not current execution authority.

## Context

Güven Gürsel has two durable but different audience jobs:

1. Establish professional authority around hydropower, operations, engineering judgement, consultancy, and applied AI.
2. Build an English-language global creator presence around local LLMs, autonomous agents, experiments, technical field notes, and build-in-public work.

The existing `guvengursel.com` model placed both jobs under one personal site. That minimized maintenance, but made positioning difficult: career credibility, consultancy, experimental AI work, and social content competed for the same information hierarchy.

The accepted Quiet Machine / Flow Continuum design exposed a stronger fit with Güven's long-used internet alias, `riverrunsagain`. The alias is authentic rather than campaign-generated and naturally connects flow, pressure, recovery, hydropower, systems, and iteration.

A live availability probe on 2026-07-31 found no Verisign RDAP registration or DNS records for `riverrunsagain.com`, and direct X, Instagram, YouTube, GitHub, and TikTok profile URLs did not expose an existing account. This evidence is time-sensitive and is not a reservation, purchase, trademark clearance, or guarantee of availability.

## Decision

Adopt an **endorsed dual-brand** architecture:

- **Güven Gürsel** is the person, trust anchor, and final authority.
- **guvengursel.com** is the professional authority and consultancy surface.
- **River Runs Again** is the global creator/media/lab brand for local-first AI systems.
- River Runs Again is visibly endorsed as "by Güven Gürsel" rather than presented as an unrelated or anonymous company.
- guvengursel.com identifies River Runs Again as Güven's creator lab.
- LinkedIn remains person-led and bridges both domains.
- River Runs Again owns creator channels such as X and YouTube when those channels are separately activated.

Content is separated by audience job, not language alone:

- Professional outcomes, hydropower, operations, consultancy, biography, and applied-AI case studies belong to guvengursel.com.
- Local LLM experiments, autonomous systems, benchmarks, engineering field notes, build logs, and creator media belong to River Runs Again.
- A crossover project may have an executive case study on guvengursel.com and a technical deep dive on River Runs Again, but each artifact has one canonical home and the other surface links to it.

Language policy:

- River Runs Again is English-first and global.
- guvengursel.com is Turkish-led editorially, while core professional pages remain eligible for Turkish and English because hydropower and consultancy are international.

Visual policy:

- Quiet Machine / Flow Continuum is the default foundation proposed for River Runs Again because the alias and interaction model reinforce each other.
- guvengursel.com receives a calmer professional sibling system using shared flow principles without duplicating the full show surface.
- Final visual contracts for both brands require a dedicated human gate before canonical source changes.

The current tracked `guvengursel.com` source remains unchanged until the roadmap's governance and visual-contract gates pass.

## Consequences

### Positive

- Each audience receives a clear reason to visit and subscribe.
- The creator brand is not tied to a short-lived "AI" name.
- Professional trust remains attached to Güven's real identity.
- The accepted Flow Continuum work becomes a reusable strategic asset rather than a discarded experiment.
- Local AI remains available as professional capability without overwhelming the consultancy site.
- Creator content can develop a global tone without forcing every career page into that voice.

### Costs

- Two sites create maintenance, content-routing, accessibility, legal, dependency, and release overhead.
- Channel proliferation can create empty accounts and split attention.
- Cross-brand content can duplicate or cannibalize search authority if canonical ownership is not enforced.
- River Runs Again can look anonymous or gimmicky if Güven's endorsement is weak.
- guvengursel.com can look like a static résumé if applied AI and current work disappear entirely.

### Mitigations

- One portfolio roadmap and one lifecycle index own current state.
- One canonical home is declared for every substantial content object.
- Only LinkedIn, X, and YouTube are first-line channels; Instagram remains deferred until a repeatable format earns it.
- No shared component package or portfolio platform is created until measured duplication justifies it.
- Every active brand must expose one next gate, one current preview, one release identity, and one lifecycle state.
- Inactive work is deliberately Paused or Archived rather than silently left stale.

## Rejected alternatives

### One undifferentiated personal brand

Rejected as the default because audience jobs and editorial voices compete, even though it has the lowest maintenance cost.

### Two independent brands with no visible endorsement

Rejected because it discards Güven's accumulated professional trust and doubles identity-building work.

### Language-only separation

Rejected because Turkish versus English does not answer which audience job each site serves.

### An agency or holding-company umbrella now

Rejected as premature abstraction. There are currently two expressions of one person, not a portfolio of independent companies.

### A creator name containing "AI", "LLM", or "agent"

Rejected because it would narrow the brand to the current technology cycle and weaken the authentic alias.

## External-action boundary

This ADR authorizes documentation and planning only. It does not authorize:

- domain purchase or registration;
- social account creation or handle reservation;
- trademark filing;
- GitHub repository creation or push;
- DNS, Cloudflare, Caddy, or hosting mutation;
- public site promotion;
- social publication or outreach;
- paid API use.

Each external action requires its own current-turn approval under the existing release and safety contracts.
